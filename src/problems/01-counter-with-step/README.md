# Counter with Step

## Problem Statement

Build a React Counter application that allows users to increment and decrement the counter by a custom step value.

## Functional Requirements

- Display the current count.
- Allow the user to enter a step value.
- Increment the counter by the entered step value.
- Decrement the counter by the entered step value.
- Reset the counter and step value.

## Concepts Covered

- React Hooks (`useState`)
- Controlled Components
- Event Handling
- Functional State Updates
- Number Conversion
- State Management

## Tech Stack

- React
- JavaScript (ES6+)
- CSS

## Learning Outcome

This project demonstrates:

- Managing multiple state variables.
- Creating controlled form inputs.
- Updating state using the previous state.
- Handling user input safely.
